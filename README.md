# Vagalume

Assistente de voz para Windows: ditado, comandos por voz, circule-e-pergunte, rotinas e uma ilha de atalhos.

**Baixar:** abra a [última versão](https://github.com/itsbravos/vagalume-releases/releases/latest) e, em **Assets**, clique em . Depois de instalado, o Vagalume se atualiza sozinho.

Este repositório guarda só os instaladores.
